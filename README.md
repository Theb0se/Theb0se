### 🚀 What I've Shipped

A few projects I've architected and built end-to-end — see pinned repos for more.

**🏨 Doorbell — Real-Time Hospitality Concierge SaaS**
Multi-tenant platform connecting in-room hotel guests to front desk & operations via a zero-login QR experience.
`Next.js · TypeScript · PostgreSQL · Prisma · Supabase Realtime`
- Architected stateless HMAC-SHA256 signed room QR tokens for tamper-resistant identity with no guest login
- Turned every hotel room into a persistent digital concierge, centralizing service requests across teams

**🏥 Orient Clinic — Patient App & Booking Portal**
Unified portal for scheduling consultations, tracking records, and managing appointments.
`Next.js · Firebase · shadcn/ui · Tailwind · React Native`
- Replaced manual front-desk booking with a real-time, self-serve scheduling workflow
- Eliminated double-bookings and cut administrative overhead for clinic staff

**🩺 Medicare — Appointment & Queue Management System**
Clinic-focused booking and live queue platform.
`React · TypeScript · Laravel · Firebase · MySQL`
- Built the full frontend, admin dashboard, and patient portal with real-time queue updates
- Helped clinics automate appointments and cut down walk-in chaos

**📚 RMP Classes — Web Platform & Mobile App**
Course-access web platform with a companion cross-platform mobile app.
`Next.js · React Native · Tailwind CSS · REST APIs`
- Optimized load speed and local search discoverability
- Drove a **35% YoY increase** in student footfall

**🧩 EasyUI — Open-Source React Component Library**
Reusable, animation-rich components for modern React interfaces.
`React · TypeScript · Tailwind CSS · Motion`
- Contributed 3 production-ready, customizable components with polished interaction states
