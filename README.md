### 👨‍💻 Executive Summary

Software Engineer with **4+ years of experience** building high-concurrency web applications, scalable SaaS architectures, and production-grade user interfaces. Delivered **20+ end-to-end applications** across healthcare, booking platforms, and enterprise CRM domains. Focused on robust frontend architecture, state synchronization, distributed caching, and zero-downtime client-server integrations.

* 🚀 **Currently Building:** A high-throughput sports turf management platform powered by Next.js, Redis lock concurrency, and Razorpay webhook pipelines.
* 🛠️ **Core Philosophy:** Component modularity, resilient state orchestration, and predictable performance across the full product lifecycle.
* 💼 **Available For:** Senior Frontend / Full-Stack engineering roles and high-impact product consulting.
